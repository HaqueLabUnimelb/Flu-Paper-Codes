# Archived figures

This directory contains 42 existing JPEG outputs whose filenames and original
output directories match explicit `ggsave()` calls in
`scripts/02_feature_plots/FeaturePlots_Flu.R`:

- 4 spatial `nFeature_RNA` QC plots;
- 27 explicitly saved cytokine-gene feature plots;
- 11 explicitly saved B-cell-associated gene feature plots.

All archived images are 1417 × 1417 baseline JPEG files. Together they occupy
22,521,698 bytes; the largest file is 874,739 bytes. The files were copied
without modification and were not regenerated during repository preparation.

Files are stored in `generated/feature_plots/`. Individual sizes and SHA-256
checksums are recorded in `docs/FIGURE_MANIFEST.tsv` and
`figures/SHA256SUMS`.

No manuscript panel numbers were present in the scripts, so manuscript mappings
remain unresolved. The images were archived based on technical provenance only;
no biological interpretation or visual relevance assessment was performed.
